SIMFONIK Script Annotation — Human Control

Healthcare Professional · Part 1 · Chapters 004–005 · Annotate independently, then export and send back

How to use this sheet. Read each script beat carefully. Use the tags below each beat to annotate it across four dimensions: inject type (what the inject is doing), mode (what it instructs the player to do), timing (how it enters the scene), and relational impact (what it does to the participant). Select as many as apply in each dimension. Add observations in the notes field. Work from your own judgement — there are no right answers. When done, click Export annotations at the bottom, copy the text, and send it back.
